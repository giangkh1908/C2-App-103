## Chat AI Branch Notes

- The `Học tập Chat với AI` flow currently supports 4 runtime topics only:
  `multiplication`, `division`, `fraction_basic`, `perimeter_area_basic`.
- Curriculum topics shown in the chat screen are reference-only and must not be bound
  directly to `selected_topic` requests until backend support exists.
- `map_scale_visual` is a known curriculum coverage gap and is intentionally left out
  of this low-conflict bugfix branch.
